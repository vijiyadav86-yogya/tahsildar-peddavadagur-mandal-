ఆటోమేటిక్ WhatsApp రిమైండర్

ఈ HTML వెర్షన్ WhatsApp సందేశాన్ని సిద్ధం చేస్తుంది; మీరు WhatsApp లో Send నొక్కాలి. గడువు రోజున ఆటోమేటిక్‌గా పంపడానికి అధికారిక WhatsApp Cloud API, Firebase Cloud Functions, భద్రమైన సర్వర్ రహస్యాలు అవసరం. పాస్‌వర్డ్ మాత్రమే పెట్టడం వల్ల Firebase డేటా భద్రత ఏర్పడదు.
